# Trust Levels

The marketplace uses four trust levels:

* `community`: schema-valid and community maintained
* `verified`: CI-valid with installability and metadata checks
* `blessed`: recommended by [BPG](https://github.com/ginstrom/bpg) maintainers and operationally mature
* `deprecated`: retained for compatibility but not recommended

See [Design](design.md) for the full trust-level criteria and promotion expectations.
