# Documentation Index

Core repository documentation for `bpg-marketplace`.

This registry complements the main [BPG](https://github.com/ginstrom/bpg) workflow platform. The marketplace catalogs reusable nodes, recipes, templates, and policies; [BPG](https://github.com/ginstrom/bpg) resolves that metadata at build time into locked execution plans and runs workflows at runtime.
