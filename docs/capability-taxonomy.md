# Capability Taxonomy

Initial capability vocabulary used by the sample registry:

* `audit_logging`
* `audit_verification`
* `compliance_reporting`
* `evidence_export`
* `human_approval`
* `hybrid_search`
* `trace_emission`
* `vector_search`
* `vector_upsert`
* `workflow_pause`
* `workflow_resume`

Capabilities should remain concise, machine-readable, and stable over time.
